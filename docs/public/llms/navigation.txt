SYMBOL NAVIGATION
=================

Name the symbol, or select a position inside it.

By name:
navigate {"action":"references","symbol":"Calculator.Add"}

symbol matches the end of the fully qualified name: Add, Calculator.Add or
MyApp.Math.Calculator.Add. A parameter list selects an overload: Calculator.Add(int, int).
Generic arguments are optional: Box.Put and Box<T>.Put are the same name.
A constructor needs its parameter list: Calculator(ILogger).
Partial declarations count as one symbol.

If the name matches several symbols, the error ambiguous_symbol lists up to 20
candidates. Each candidate symbol can be sent back unchanged. symbol_not_found means
no declaration matched. Use the symbols tool to search by partial name.

By position (file is workspace-relative, line and character are one-based,
character counts UTF-16 code units):
navigate {"action":"definition","file":"src/Calculator.cs","line":12,"character":9}

Replace action with:
type_definition - Find the symbol's type definition.
implementation - Find implementations of an interface or abstract member.
references - Find references, including the declaration.
callers - Find the methods that call this method, with their call sites.
callees - Find the methods this method calls, with the call sites in this file.
supertypes - Find the base types and interfaces of a type.
subtypes - Find the types that derive from or implement a type.
hover - Read type information and documentation.

SYMBOL SEARCH
-------------
Document symbols:
symbols {"file":"src/Calculator.cs"}

Workspace symbols:
symbols {"query":"Calculator","limit":50}

For workspace search, omit file. When file is present, query is not used.
Use symbols to locate a declaration, then navigation for semantic relationships.

RESULTS
-------
Definition, type_definition, implementation and references return:
{"items":[{"file":"src/Foo.cs","positions":[[42,17],[81,9]]}],"total":2,"truncated":false}
Positions are [line, character], both one-based, with UTF-16 characters.
Files inside the workspace use relative paths. External and generated locations
keep their absolute URI. Location links use the target selection start.
total counts occurrences before limiting. limit caps occurrences, not files.
limit defaults to 50 and accepts 1 through 250. Inspect truncated before claiming
a complete reference or implementation list. No matches returns items: [].

callers, callees, supertypes and subtypes return:
{"items":[{"name":"Consumer.Run(IGreeter)","kind":"method","file":"src/Consumer.cs","position":[7,26],"calls":[[7,59]]}],"total":1,"truncated":false}
calls is present only for callers and callees.

Symbols return items with name, kind, file and position. Document symbols omit
file and nest members in children. Hover returns {"text":"..."} in Markdown.
Use the lsp tool with action=request for raw LSP locations, full ranges and location link metadata.
