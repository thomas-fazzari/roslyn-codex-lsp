SYMBOL NAVIGATION
=================

Select a position inside the symbol. file is workspace-relative.
line and character are one-based. character counts UTF-16 code units.

Definition:
{"request":{"action":"definition","file":"src/Calculator.cs","line":12,"character":9}}

Replace action with:
type_definition - Find the symbol's type definition.
implementation - Find implementations of an interface or abstract member.
references - Find references, including the declaration.
hover - Read type information and documentation.

SYMBOL SEARCH
-------------
Document symbols:
{"request":{"action":"symbols","file":"src/Calculator.cs"}}

Workspace symbols:
{"request":{"action":"symbols","query":"Calculator","limit":50}}

For workspace search, omit file. When file is present, query is not used.
Use symbols to locate a declaration, then navigation for semantic relationships.

RESULTS
-------
Definition, type_definition, implementation and references return:
{"items":[{"file":"src/Foo.cs","positions":[[42,17],[81,9]]}],"total":2,"truncated":false}
Positions are [line, character], both one-based, with UTF-16 characters.
Files inside the workspace use relative paths. External and generated locations
keep their absolute URI. Location links use the target selection start.
total counts occurrences before limiting. limit caps occurrences, not files.
limit defaults to 50 and accepts 1 through 250. Inspect truncated before claiming
a complete reference or implementation list. No matches returns items: [].

Hover and symbols preserve Roslyn's LSP shapes and zero-based positions.
Use action=request for raw LSP locations, full ranges and location link metadata.
